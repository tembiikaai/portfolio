# Portfolio Website

This repository contains the source for my personal portfolio. The main page is `index.html`, which showcases my background and selected work.

To view the page locally, clone the repo and open `index.html` in a web browser or serve the directory with any static web server.

The HTML page includes sections for:

- **About Me** – a short introduction.
- **Projects** – highlights of notable projects.
- **Skills** – technologies and tools I use.
- **Contact** – ways to get in touch.

Feel free to explore or use this layout as a starting point for your own portfolio.
